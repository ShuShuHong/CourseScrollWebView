## 二、输出网格怎么定的

输出一小节 **2.5100 s**，**30 小节 = 75.30 s**，再接 **1.51 s 尾音** = **76.81 s**。

选它只有一个原因：**公蟹撞线 65.26 s 正好落在第 26 小节之后的正拍上**（65.26 / 2.51 = 26.00，偏差 **0 ms**）。
主舞台 62.75 s 也刚好卡在第 25 小节。

与原曲的差别：2.5100 / 2.5078 = **+0.088 %**（≈1.5 音分）。这点差距用「输出采样点在源文件里线性插值」实现，
等于整首降 1.5 音分 —— 人耳听不出，而且**没有相位声码器的糊瞬态问题**（鼓点不会散）。

## 四、接头质量

7 个剪点全在小节线上，首尾各 1.5 ms 淡化。实测：

```
爆音比（接缝处跳变 / 本地 99.9 分位）：0.00× ×7   —— 没有“咔”
和声相似度（接头两侧 0.4 s 的色度余弦）：0.66 / 0.81 / 0.85 / 0.92 / 0.93 / 0.94 / 0.96
```

最低的 0.66 在 17.57 s（b2→b3，原曲 bar7 → bar13，本来就是 A/B 段交界），其余都 ≥0.81。
